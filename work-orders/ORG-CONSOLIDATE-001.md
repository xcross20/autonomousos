# ORG-CONSOLIDATE-001 — Cross-repository capability recovery

## Mission
Create a complete, evidence-backed constituent-part inventory and executable integration proposal for a reusable autonomous product organization. **This phase is discovery only.**

## Sources
- xcross20/ventureos: main; feat/org-boot-001-ventureos; relevant historical V1–V4 branches.
- xcross20/rally_top_signal_tester: main; feat/org-boot-001-rally; relevant autonomy/research branches.
- xcross20/Council_lab: remote and local experiment branches/worktrees.
- Engineering Runtime / FDE: discover real repository URL, local worktrees and unpushed changes.
- Search the user's local code workspaces for STRATEGY.md, RETHINK.md, NEXT.md, STATE.md, prompts, skills, runtime controllers and reviewed decisions.

## Outputs
1. Repo/branch ledger: URL, SHA, working tree, pushed versus local-only status; missing access recorded as UNKNOWN.
2. File-level component catalog: governor, permissions, scheduling, builders, reviewers, bounded runtimes, recovery, research, councils, emergence, strategic rethink, prompts, CLI/UI, state and telemetry.
3. Interface/test ledger: inputs/outputs, exact source file and SHA, consumers, dependencies, tests actually run and limitations.
4. Duplication/compatibility matrix: choose one owner for job state, approval authority, runtime execution and scope leases.
5. ADOPT/ADAPT/REFERENCE/ARCHIVE/REJECT recommendations with licensing, migration risk and provenance.
6. Minimal pilot design: new-repo bootstrap → approved vertical slice → bounded build → independent review → product evidence → rethink proposal → human authority gate → next work, with restart recovery.
7. Complexity/cost budget: measure tokens, setup time, time to accepted work, review defects, human touchpoints, external provider costs. Do not invent benchmarks.
8. Recommendation whether autonomousos is permanent canonical host or temporary consolidation workspace beside VentureOS.

## Guardrails
All source repositories are read-only in this phase. Do not move or copy source code, modify existing workflows, push or merge to other repos, deploy, consume paid APIs without explicit approval, or handle production secrets. Keep Rally product work uninterrupted.

## Acceptance
Independent reviewer checks the inventory against source files, confirms overlapping responsibilities and flags inaccessible local evidence. The result is READY_FOR_HUMAN_REVIEW, not automatic acceptance. Stop before runtime migration.
